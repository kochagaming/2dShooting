# VELOCITY//BREAKER — Prototype 01

公開URL（GitHub Pages）: https://kochagaming.github.io/2dShooting/

弾幕を安全に避けるのではなく、敵弾へ踏み込み、NEAR MISSでBOOSTを奪って加速する高速縦スクロール・ラン＆ガンの操作感検証プロトタイプです。

## 使用技術

- HTML5 Canvas / CSS / JavaScript（ES Modules）
- Web Audio API（外部音源なしのリアルタイム効果音）
- Node.js標準テストランナー

外部ライブラリには依存せず、キャラクター画像とCanvas描画のパーティクルを組み合わせています。

## 起動方法

Node.jsがある環境で、プロジェクトのディレクトリから次を実行します。

```sh
npm run serve
```

ブラウザで `http://127.0.0.1:4173` を開いてください。

テストは次のコマンドで実行できます。

```sh
npm test
```

## 操作方法

| 操作 | キー |
| --- | --- |
| 8方向移動 | WASD / 矢印キー |
| 射撃（長押し連射） | Z / J / 左クリック |
| ダッシュ | Space / Shift |
| スライディング | C / Ctrl |
| 斬撃・敵弾破壊 | X / K / 右クリック |
| 銃の切替 | Q |
| ポーズ | P |
| 操作ガイドを開閉 | H / Escで閉じる |
| デバッグ表示 | F3 |
| 開始・リスタート | Enter |

マウス射撃時はカーソル方向へ、キー射撃時は前方へ撃ちます。移動入力を入れずにダッシュすると前方へ進みます。高速移動中に逆方向へ入力すると急旋回し、短い火花とカメラ遅延が発生します。

操作ガイド内のKEY CONFIGから、射撃・ダッシュ・斬撃・スライディング・武器切替の主要キーを変更できます。設定はブラウザに保存され、重複キーを指定した場合は既存割り当てと自動交換されます。

スマートフォンでは、画面左下のバーチャルスティックで移動し、右下の `FIRE`（最寄りの敵へ自動照準）、`DASH`、`SLASH`、`SLIDE`、`WEAPON` ボタンで操作できます。縦向きでのプレイを推奨します。

標準ゲームパッドでは、左スティックで移動、`A / RT`で射撃、`LB / RB`でダッシュ、`X`で斬撃、`B`でスライディング、`Y`で武器切替、`START`でポーズできます。

- STAGE 1は1ウェーブ、STAGE 2は2ウェーブと段階的に増え、STAGE 10は10ウェーブ。各ステージ最終ウェーブはボス戦
- 最終ウェーブ開始直後にはボスを出さず、通常敵と走行ギミックを一定時間突破した後に追撃ボスが出現。STAGE 1でも操作を試す時間を確保
- HUDに現在ウェーブの進行ゲージと、次ウェーブ／ボス出現までの秒数を表示。ボス出現後はBOSS ENGAGEDへ切替

- 各ステージ固有の全10ボスが登場。狙撃、回転弾、レーン封鎖、挟撃など固有弾幕を持ち、撃破までステージクリアにならない

## 周回と強化

敵から回収したDRIVE COREは挑戦終了時に所持素材へ加算されます。リザルトの「UPGRADE」またはTOP画面の「SELECT LOADOUT」からキャラクターを選び、衣装選択画面下部の「恒久強化」で使用してください。強化内容はキャラクターごとに独立しており、次回以降の挑戦へ引き継がれます。

REPAIRは挑戦中に拾うとその場でHPを回復します。画面上部には現在のステージ、ウェーブ、挑戦中に回収したDRIVE COREが表示されます。
