# VELOCITY//BREAKER — Prototype 01

公開URL（GitHub Pages）: https://kochagaming.github.io/2dShooting/

弾幕を安全に避けるのではなく、敵弾へ踏み込み、NEAR MISSでBOOSTを奪って加速する高速縦スクロール・ラン＆ガンの操作感検証プロトタイプです。

## 使用技術

- HTML5 Canvas / CSS / JavaScript（ES Modules）
- Web Audio API（外部音源なしのリアルタイム効果音）
- Node.js標準テストランナー

外部ライブラリには依存せず、キャラクター画像とCanvas描画のパーティクルを組み合わせています。

## 起動方法

Node.jsがある環境で、プロジェクトのディレクトリから次を実行します。

```sh
npm run serve
```

ブラウザで `http://127.0.0.1:4173` を開いてください。

テストは次のコマンドで実行できます。

```sh
npm test
```

## 操作方法

| 操作 | キー |
| --- | --- |
| 8方向移動 | WASD / 矢印キー |
| 射撃（長押し連射） | Z / J / 左クリック |
| ダッシュ | Space / Shift |
| スライディング | C / Ctrl |
| 斬撃・敵弾破壊 | X / K / 右クリック |
| 銃の切替 | Q |
| ポーズ | P |
| 操作ガイドを開閉 | H / Escで閉じる |
| デバッグ表示 | F3 |
| 開始・リスタート | Enter |

マウス射撃時はカーソル方向へ、キー射撃時は前方へ撃ちます。移動入力を入れずにダッシュすると前方へ進みます。高速移動中に逆方向へ入力すると急旋回し、短い火花とカメラ遅延が発生します。

## 現在実装済み

- 慣性と即応性を両立した8方向移動、街道の可変スクロール
- 「キャラクター選択 → 衣装選択」の2段階ロードアウト画面とブラウザ内への選択保存
- 万能型レイ、射撃・耐久型ミラ、近接・機動型リンの3キャラクター
- キャラクター／衣装選択では正面全身を表示し、「背後から見る」でゲーム中の背面へ即時切替
- TOP画面の「操作説明」ボタンまたはHキーで、ゲーム画面と重ならない全画面操作ガイドを表示
- キャラクターごとにHP、移動速度、連射速度、射撃威力、弾速、ダッシュ性能、斬撃範囲・威力・クールダウンが変化
- レイ、ミラ、リンそれぞれ5衣装、計15セットの正面／背面アート。選択した背面衣装がゲーム中にも反映
- 「挑戦 → 報酬確定 → 恒久強化 → 再挑戦」の周回ループ
- VERDANT ROUTE／RED WASTE／FROSTLINEの3ステージと、各5ウェーブの進行
- ステージ・ウェーブごとに敵のHP、射撃頻度、出現量、敵種構成が変化
- 第5ウェーブに草原のPURSUER、荒野のDREADNOUGHT、雪原のWHITE FANGが出現。各ボス固有の照準弾、扇状弾、挟撃弾を持ち、撃破まで次ステージへ進行しない
- PURSUER撃破でDRIVE CORE 5個、BOOST、追加スコアを獲得
- 敵撃破時に確率でDRIVE CORE（強化素材）またはREPAIR（HP回復）をドロップ
- キャラクター別の5系統・各5段階の恒久強化（HP、移動、射撃、斬撃、ダッシュ）
- キャラクター選択後に、強化反映済みのHP・移動・射撃・ダッシュ・斬撃実数を表示
- 強化素材・強化段階・選択ロードアウトをブラウザへ保存
- 恒久強化はキャラクター選択後の衣装画面でのみ実行可能
- 無敵時間・残像・画面揺れ・速度ストレッチ付きダッシュ
- 小さい当たり判定と土煙を持つスライディング、高速中の逆入力による急旋回
- ダッシュ開始直後の弾際を判定するJUST DODGE。通常のダッシュ回避よりBOOSTとスコアが高い
- プレイヤー速度に遅れて追従するカメラと、BOOST段階に応じて増えるスピードライン
- 通常走行を約700～900km/h、ダッシュを約1,100～1,500km/hとして見せる速度表示と背景流速
- 遠近ストリーク、路肩の自然物、路面残像、ダッシュ後まで残るズーム・衝撃リング・三重の推進光
- ステージごとに草原街道、赤土の荒野、雪原へ変化する、低彩度で弾幕を見分けやすい自然背景
- ウェーブ進行に応じて風車、岩場、枯れ木、針葉樹、雨、砂嵐、吹雪、ボス接近時の暗転が追加される背景変化
- 中央の暗い道路、透視グリッド、流れる路面継ぎ目、外周中心の白い速度線で視認性と疾走感を両立
- マウスエイム／前方連射、ヒットエフェクト、敵ノックバック
- Qで切り替えるハンドガン、ショットガン、レーザー、追尾ミサイル
- 通常射撃、5-way弾幕、照準射撃を行う3種の敵
- 敵は一定時間後に画面下へ離脱を開始。逃すとBOOSTが7減少してコンボが途切れるため、安全地帯での待機より積極的な追撃が有利
- 全敵に射撃前の警告リングを追加。狙撃敵とPURSUERは着弾方向が分かる照準線・照準マーカーを表示
- 通常斬撃、敵弾破壊、近距離ターゲットへ吸着する広範囲・高威力のダッシュ斬り
- ダッシュ斬り撃破時のダッシュ再装填と、遅れて爆発する追撃演出
- 通常／ダッシュを区別するNEAR MISSとBOOST報酬
- 5段階BOOST、OVERDRIVE、速度・連射・ダッシュ強化
- コンボ、スコア、HP、速度表示、切替式デバッグ情報
- Vキーで切り替えるCOMBAT FOCUS。背景・天候・速度線を暗く抑え、画面揺れ・ズーム・被弾フラッシュを軽減して弾幕の視認性を優先
- ヒットストップ、爆発、パーティクル、残像、スピードライン、効果音
- ゲームオーバーと即時リスタート、ポーズ
- 3ステージ目のWHITE FANG撃破でMISSION CLEAR。完走ボーナスのDRIVE CORE 8個を加算し、専用リザルトから次の挑戦または強化へ進行
- スコア、撃破数、NEAR MISS、被弾数、時間から算出するD～SランクのRUN REPORT
- キャラクター別に最高スコア、最高ランク、最速クリア時間、クリア回数をブラウザへ保存し、TOP画面とリザルトで新記録を表示
- VERDANT ROUTEの開けた草原、風車、石積み、雨雲、追撃兵器接近など、ウェーブ連動の背景イベント
- VERDANT ROUTEに実体のある交通車両・道路封鎖・BOOSTランプを配置。衝突被害、ギリギリ通過報酬、ランプ加速が発生
- RED WASTEには峡谷ゲート、FROSTLINEには左右へ動く狭いアイスグリッドが出現。隙間を正確に高速通過するとBOOSTとスコアを獲得
- 挑戦ごとにNEAR MISS、ダッシュ斬り撃破、OVERDRIVE維持のいずれかを要求するRUN ORDERが発生。達成すると追加DRIVE COREを獲得

## 周回と強化

敵から回収したDRIVE COREは挑戦終了時に所持素材へ加算されます。リザルトの「UPGRADE」またはTOP画面の「SELECT LOADOUT」からキャラクターを選び、衣装選択画面下部の「恒久強化」で使用してください。強化内容はキャラクターごとに独立しており、次回以降の挑戦へ引き継がれます。

REPAIRは挑戦中に拾うとその場でHPを回復します。画面上部には現在のステージ、ウェーブ、挑戦中に回収したDRIVE COREが表示されます。
